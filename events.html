How the semester runs

  1. Weeks 1–2Recruitment: Core Membership & Track applications open, kickoff info session
  2. Weeks 3–10Weekly Fundamentals cohorts run in parallel; biweekly seminar talks interleaved
  3. Week 6Mid-semester hackathon / red-teaming sprint
  4. Weeks 8–10Capstone work begins
  5. Weeks 10–12Research Fellowship applications open for Fundamentals graduates
  6. Weeks 12–14Capstone presentations / demo day
  7. Week 15This cohort’s graduates recruited as next semester’s facilitators
